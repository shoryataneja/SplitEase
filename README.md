# SplitEase

SplitEase is a full-stack web application that helps groups split expenses during trips and events in a simple and fair way.

## Features (Planned)
- User authentication (Signup & Login)
- Create trips and add members
- Add expenses and split equally
- View balances (who owes whom)

## Tech Stack (Planned)
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
